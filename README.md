# Просвет

Обход DPI для YouTube, Discord, Telegram, Rainbow Six Siege, For Honor и любых ваших сайтов.
Работает на всех Linux и на Windows. Сам определяет систему, сам подбирает стратегию
под вашего провайдера, **сам выводит новые рецепты**, если готовые не справляются,
и чинит их, когда провайдер что-то меняет.

Внутри — движок [zapret](https://github.com/bol-van/zapret) (nfqws на Linux, winws на Windows).
Снаружи — полноэкранный консольный интерфейс: один файл, никаких зависимостей.

## Чем лучше, чем zapret-discord-youtube от Flowseal

| | Flowseal | Просвет |
|---|---|---|
| Выбор стратегии | 22 готовых `.bat`, перебирать вручную | **автоподбор** по группам трафика: YouTube, Discord, Telegram, игры, хостинги — каждая группа получает свой лучший рецепт |
| Новые стратегии | только те, что в архиве | **селекция**: рабочие рецепты разбираются на «гены» (способ разреза, отсев фейков, приманка, повторы…), скрещиваются и мутируют; потомки проверяются на вашей сети. Лучшие сохраняются и предлагаются в следующих подборах |
| Один рецепт на всё | одна стратегия на весь трафик, даже если части она вредит | ищется **универсальный** рецепт, который работает для всех TLS-групп не хуже их собственных чемпионов; если найден — ставится везде |
| Если сервис работает и так | всё равно гоняет через фейки | сначала проверка без обхода; работающее не трогаем |
| Фейки | фиксированные `.bin` (у `max_ru.bin` внутри на самом деле `www.onetrust.com`) | генерируются на лету для любого имени: TLS ClientHello с отпечатком Chrome и QUIC Initial по RFC 9001 |
| «Фейк дошёл до сервера» | не видно, просто «не работает» | распознаётся, и все рецепты с тем же способом отсева отбрасываются |
| Типы блокировки | — | различает: сброс по SNI, потерю рукопожатия, заморозку 16–20 КБ, блок по IP, подмену DNS, UDP без ответа |
| Telegram | нет (отдельный проект tg-ws-proxy на Python) | встроенный MTProto-прокси через WebSocket, как у web.telegram.org: гонка маршрутов, пул заранее открытых соединений, запасной путь по TCP. Работает без прав администратора |
| Пинг в Siege и For Honor | весь UDP 1024–65535 через WinDivert, ×12 фейков на каждый поток | см. ниже: путь мимо VPN, ближайший дата-центр, в ядре — только первые пакеты потока, рецепты ранжируются по пингу и числу лишних пакетов |
| Когда стратегия перестала работать | ищите новый `.bat` | **самовосстановление**: служба проверяет цели и переподбирает только сломанную группу |
| Linux | нет (только порты от сообщества) | systemd, OpenRC, runit, dinit, SysV; nftables или iptables+ipset; Arch, Debian/Ubuntu, Fedora, openSUSE, Alpine, Void, Gentoo, NixOS (модуль), SteamOS/Silverblue |
| Мешающие программы | диагностика в `service.bat` | находит Flowseal, GoodbyeDPI, ByeDPI, Killer, SmartByte, Check Point, Intel Connectivity и предлагает остановить |
| Антивирус «вылечил» winws | переустанавливать | оригиналы встроены и сверяются по SHA-256 при каждом запуске службы |
| Безопасность | — | служба принимает только проверенные рецепты; опции вроде `--debug=@/etc/...` и пути к файлам отвергаются — и в каталоге, и у выведенных рецептов |

## Быстрый старт

Скачайте архив под свою систему со страницы [последнего релиза](https://github.com/FrainTX/zapret/releases/latest).

**Windows 10/11.** Распакуйте `prosvet-…-windows-amd64.zip` и откройте `zapret.bat`.
В первый раз он попросит права администратора, установит службу, подберёт стратегию
и откроет панель; потом — просто открывает панель.

**Linux.**
```bash
tar xzf prosvet-*-linux-amd64.tar.gz && cd prosvet-*-linux-amd64
```
```bash
./install.sh
```
Установщик сам определит дистрибутив, init-систему и файрвол, поставит службу, запустит
подбор и создаст команду `zapret`. Дальше в любой папке:
```bash
zapret
```
— откроется панель, без sudo (пользователь, установивший программу, и члены групп
`wheel`/`sudo` управляют службой напрямую). Если команда `zapret` уже занята старым
zapret-discord-youtube, установщик спросит и сохранит её как `zapret-old`;
`prosvet uninstall` вернёт всё как было.

## Интерфейс

`zapret` (или `prosvet`) без аргументов открывает полноэкранный интерфейс:

| Вкладка | Что там |
|---|---|
| 1 Обзор | плитки «Обход · Доступность · Пинг игр · Telegram», таблица групп с рецептами, результатами и историей задержки |
| 2 Подбор | живая матрица: каждая клетка — проверенный рецепт (◆ — выведенный селекцией), этапы, поколения, универсальный рецепт |
| 3 Игры | пинг до 13 дата-центров Siege, игровой UDP через VPN и напрямую, закрепление ближайшего дата-центра |
| 4 Telegram | ссылка для Telegram Desktop, соединения, трафик, маршруты к дата-центрам |
| 5 Цели | что обходить, свои сайты, исключения |
| 6 Журнал | журнал службы |
| 7 Система | платформа, движок, конфликты, установка |

Палитра — «свет сквозь щель»: холодные чернила и сланец, один ледяной луч для того, что проходит,
мягкий жёлтый — «частично», розовый — «заблокировано».

## Как работает подбор

1. **Без обхода.** Каждая цель проверяется напрямую. Если открывается, её не трогаем.
2. **Рецепты.** 30+ рецептов zapret (все стратегии Flowseal, разобранные на составляющие, плюс
   варианты из `blockcheck`) и рецепты, выведенные на прошлых подборах. Каждая группа живёт
   в своём профиле nfqws/winws, поэтому группы проверяются одновременно и не мешают друг другу.
3. **Приманки.** Для лучших рецептов перебираются имена из белого списка ТСПУ
   (`max.ru`, `vk.com`, `4pda.to`, `gosuslugi.ru`, `www.google.com`…).
4. **Селекция.** Из лучших рецептов каждой группы рождаются потомки: гены родителей
   скрещиваются, одна-две мутации (повторы, способ отсева, точка разреза, перекрытие,
   приманка, отсечка для UDP), затем «починка» — опции, которые выбранный режим игнорирует,
   убираются, нужные добавляются. Каждый потомок проходит валидатор; на тестах **978 случайных
   потомков приняты настоящим nfqws** без единой ошибки. Если ничего не работает, родители
   берутся из разных семейств техник и мутируют сильнее.
5. **Универсальный рецепт.** Победители групп и их скрещивания проверяются сразу на всех
   TLS-группах; рецепт, который везде не хуже местных чемпионов, становится общим.
6. **Проверка.** Итоговая связка гоняется дважды; нестабильный рецепт заменяется следующим.

`prosvet tune` — быстрый подбор (2 поколения селекции, только для групп, где есть что улучшать,
и для игр). `--deep` — 4 поколения для всех. `--synth N` — сколько угодно (до 12).

## Rainbow Six Siege и For Honor: минимальный пинг

С конца 2025 года ТСПУ ограничивает соединения с зарубежными облаками. Ubisoft Connect живёт
на AWS, матчмейкинг Siege — на PlayFab в Azure, выделенные серверы For Honor — у i3D.net.

Пинг складывается из пути до сервера и того, что добавляет обход. Просвет работает с обоими:

- **Мимо VPN.** Если маршрут по умолчанию — VPN (Happ, v2rayN, Hiddify, sing-box, AmneziaWG,
  WireGuard…), каждый игровой пакет делает крюк через сервер VPN. На тестовой машине с Happ
  UDP до AWS Франкфурт шёл **274 мс через VPN и 47 мс напрямую**. На Linux Просвет сам
  отправляет игровой UDP к игровым подсетям через физический шлюз (метка nftables → отдельная
  таблица маршрутизации → маскарадинг), включая фейки движка; при выключении всё убирается.
  Включается автоматически, когда работают цели R6/For Honor (`prosvet games direct off` —
  отключить). На Windows интерфейс покажет, какие `.exe` добавить в исключения VPN-клиента.
- **Ближайший дата-центр Siege.** `prosvet games` меряет путь до 13 регионов PlayFab
  (7 замеров на регион, учитываются разброс и потери; в обход VPN, если он есть).
  `prosvet games pin` пишет `DataCenterHint=playfab/<регион>` в `GameSettings.ini` — Windows,
  Steam/Proton, Heroic, Lutris, Bottles — с резервной копией; `prosvet games restore` возвращает.
- **Только первые пакеты.** На Linux в очередь движка уходят ровно столько пакетов потока,
  сколько рецепту нужно (по его `--dpi-desync-cutoff`): для игрового UDP — 3 вместо 12.
  Дальше игра идёт целиком в ядре.
- **Ранжирование по пингу.** Для игровых групп при равной работе выигрывает рецепт
  с меньшей задержкой (порог 3 мс), а при равной задержке — с меньшим числом лишних пакетов.
  Селекция ищет именно такие.

## Telegram

Встроенный MTProto-прокси (идея — [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy),
переписано на Go): Telegram Desktop подключается к `127.0.0.1:1443`, прокси расшифровывает
obfuscated2-рукопожатие и ведёт трафик к дата-центру через WebSocket `kws*.web.telegram.org`
(с запасным фронтингом и прямым TCP). Маршруты гонятся параллельно, лучшие держатся
открытыми заранее. Проверено вживую: DC1, DC2, DC4, DC5 и медиа-DC отвечают на `req_pq_multi`.

```bash
prosvet telegram
```
Со службой — покажет ссылку (`prosvet enable telegram`), без службы — запустит прокси прямо
в окне, права администратора не нужны.

## Обновления

Служба сама проверяет релизы на GitHub через 3–5 минут после старта и потом каждые 6 часов
и ставит новую версию без вашего участия: скачивает архив под свою платформу, проверяет
SHA-256 и **подпись ed25519** списка `SHA256SUMS`, убеждается, что новый файл запускается,
подменяет себя и перезапускается (на Linux — в том же процессе, на Windows — через
восстановление службы). Неподписанный или подменённый релиз не установится, даже если
кто-то получит доступ к GitHub-аккаунту: ключ подписи живёт только у мейнтейнера
(`~/.config/prosvet-release/signing.key`) и в секрете CI `PROSVET_SIGNING_KEY`.

```bash
prosvet update
```
— проверить и обновиться сейчас; `--check` — только проверить, `--auto off` — выключить
автообновление, `--mirror https://ваш.сервер/prosvet` — своё зеркало на случай недоступности
GitHub (раскладка: `latest` с тегом и папка `<тег>/` с теми же файлами, что в релизе).

Выпуск версии: `scripts/release.sh 1.0.1` — тег уходит на GitHub, Actions собирают все
платформы, подписывают и публикуют релиз.

## Как устроено

```
cmd/prosvet         одна программа: интерфейс, команды, служба
internal/tui        полноэкранный интерфейс (Bubble Tea + Lip Gloss)
internal/strategy   группы, каталог, гены рецептов и селекция, сборка командной строки, валидатор
internal/tuner      автоподбор: перебор, приманки, селекция, универсальный рецепт, проверка
internal/games      пинг до дата-центров, GameSettings.ini Siege
internal/netroute   определение VPN и физического шлюза
internal/tgproxy    MTProto-прокси через WebSocket
internal/fakes      TLS ClientHello и QUIC Initial (проверено векторами RFC 9001)
internal/probe      проверки: HTTPS, POST 64 КБ (16–20), QUIC, UDP-эхо, STUN
internal/engine     встроенный zapret, файлы, процесс движка
internal/firewall   nftables (+ маршрут игр мимо VPN) / iptables+ipset
internal/core       контроллер: старт/стоп, подбор, самовосстановление, Telegram
internal/daemon     локальный API (unix-сокет / именованный канал) с проверкой прав
internal/service    systemd, OpenRC, runit, dinit, SysV, служба Windows
internal/lists      домены и IP-диапазоны провайдеров
```

## Сборка

```bash
scripts/build.sh
```
Скрипт сам скачает Go в `.toolchain/`, если его нет. Всё собирается без cgo, Windows —
кросс-компиляцией. Движок zapret обновляется командой `scripts/fetch-engine.sh v72.xx`
(с проверкой SHA-256 по `sha256sum.txt` релиза).

## Что проверено, а что нет

Проверено автоматически:
- каждый из 697 вариантов командной строки каталога и 978 случайно выведенных рецептов
  принимает настоящий nfqws v72.13 (`--dry-run`);
- селекция на смоделированной сети, где рабочий рецепт не входит ни в один каталог,
  находит его и делает универсальным (29 из 30 случайных запусков);
- служба целиком в изолированном сетевом пространстве с «VPN»-туннелем по умолчанию:
  без Просвета игровой UDP теряется в туннеле, с ним — доходит через физический шлюз вместе
  с 12 фейками движка; после остановки правила и маршруты убираются;
- правка `GameSettings.ini`: сохраняются окончания строк, есть резервная копия и откат;
- Telegram-прокси вживую через WebSocket на всех дата-центрах;
- интерфейс: все вкладки в псевдотерминале, снимки экранов.

Не проверено на живом железе:
- сам обход DPI на реальном провайдере — нужны права root; тест не запускался без вашего
  разрешения (на время теста остановите `zapret-discord-youtube.service`);
- маршрут игр мимо VPN на вашей машине с Happ: проверен в изолированном пространстве, но не
  с настоящим клиентом Happ (если клиент ставит свои правила nftables «strict route»,
  их может понадобиться ослабить);
- Windows-сборки: собраны и проходят `go vet`, но не запускались на реальной Windows.
